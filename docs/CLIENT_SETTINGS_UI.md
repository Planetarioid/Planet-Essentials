# Planet Client Settings UI Direction

Planet Essentials is the intended front door for the client's settings experience. The Options entry point is already redirected to the Planet hub. The hub and Prism panel now use a shared dark, panel-based visual direction with a cyan accent, compact uppercase labels, and a client-style hierarchy.

This is an initial visual pass, not a claim that every vanilla setting has been migrated. The current bypass to the vanilla OptionsScreen has been removed from the Planet hub, but Minecraft's individual settings still need deliberate migration into equivalent Planet pages before the vanilla controls can be retired safely. Input, accessibility, video, audio, language, chat, controls, resource packs, and telemetry-related options must retain their existing behavior and persistence during that migration. Keep an advanced recovery path until parity is demonstrated.
